# Gravity Falls Cat Tarot — AI Image Prompts

Use these prompts with **DALL-E**, **Midjourney**, **Stable Diffusion**, **Leonardo.ai**, or any AI image generator.

> **Tip**: For best results in Midjourney, append `--style raw --ar 3:5` to each prompt.
> For Stable Diffusion, use the **Gravity Falls** or **Cartoon Network** LoRA if available.

---

## Prompt Format (copy and customize per card)

```
[Card Description], Gravity Falls cartoon style, bold thick black outlines, flat color fills, hand-drawn wobbly lines, pine tree forest background, mysterious symbols, no shading, Alex Hirsch art style, 2D cartoon, 220x300 aspect ratio
```

## Recommended Tools & Settings

| Tool | Best for | Settings |
|------|----------|----------|
| **DALL-E 3** | Clean, consistent style | Use the detailed prompts above verbatim |
| **Midjourney** | Artistic, painterly feel | Add: `--style raw --ar 3:5 --chaos 10` |
| **Stable Diffusion** | Custom control | Use **Gravity Falls** LoRA + **Cartoon** checkpoint |
| **Leonardo.ai** | Quick generation | Use **Vibrant Cartoon** model |
| **Ideogram** | Text-in-image (card names) | Great for putting card names directly in images |
| **Flux (Replicate)** | High quality | Use `flux-dev` model |

## After Generating Images

Once you have the AI-generated images:
1. Save them as `card-00.webp`, `card-01.webp`, etc. in `apps/tarot/assets/cards/`
2. Update `app.js` to point to `.webp` instead of `.svg`
3. Or keep them as `.jpg` and update the paths accordingly
